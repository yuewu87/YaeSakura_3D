MMD → FBX 管线 + 初始场景方案

角色模型管线

MMD 模型 (.pmx + .vmd)
    │
    ▼  Blender (插件: mmd_tools / blender_mmd_tools)
    │   · 导入 PMX 模型 + 贴图
    │   · 修正材质、贴图路径
    │   · 导出 FBX (含骨架 + BlendShape)
    │
    ▼  Unity
    │   · 导入 FBX (Rig: Humanoid 或 Generic)
    │   · 配置材质 (Shader: URP Lit)
    │   · 提取 Animation Clip (如果有动作)
    │   · 配置 BlendShape 映射 (口型、表情)
    │
    ▼  Animator Controller
        · Idle 动画循环
        · 口型 BlendShape (Mouth_Open → 0~1)
        · 表情 BlendShape (Smile / Surprised / Sad)

初始场景 — 两步走

第1步：先跑起来

  • 简单地面 + 天空盒
  • 角色站中心，镜头正对
  • Chat UI 覆盖
  • LLM + TTS 直连
  • 快速验证核心交互

目标：1-2 天能看到效果

第2步：神社场景

  • 寻找/搭建八重村场景
  • 鸟居、樱花树、神社建筑
  • 粒子效果 (樱花瓣)
  • 光照烘焙
  • 后处理 (Bloom, Color Grading)
