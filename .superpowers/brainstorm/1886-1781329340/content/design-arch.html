数据流（一次对话的完整流程）

用户输入文字
    │
    ▼
ChatManager.SendMessage(text)
    │
    ├─► 拼装 Message History (角色设定 + 对话历史)
    │
    ├─► LLM Client.SendStreaming(request)
    │       │
    │       ├─► onChunk(text) ──► ChatPanel 逐字更新气泡
    │       │
    │       └─► onComplete(fullText)
    │               │
    │               ├─► 断句拆分 (按。！？)
    │               │
    │               ├─► TTS Client.Synthesize(sentence)
    │               │       └─► WebSocket → GPT-SoVITS
    │               │       └─► 接收音频 → AudioSource.Play()
    │               │
    │               └─► 更新对话历史
    │
    ▼
