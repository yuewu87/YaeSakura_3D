UI 实现要点

对话气泡 ScrollView + ContentSizeFitter，用户右侧蓝色，角色左侧紫色
流式逐字 每收到 chunk 更新 Text 组件内容，遇。！？断句创建新气泡
动作行 括号内容提取为独立居中 Text，灰色斜体，与对话气泡分开
输入框 InputField 多行 + 回车发送 (Shift+回车换行) + 发送按钮
设置面板 侧边栏滑出 (Animator)，API 配置、TTS 连接、自动回复等
API Key PlayerPrefs 存储（gitignore 替代 .env），非敏感配置用 JSON
